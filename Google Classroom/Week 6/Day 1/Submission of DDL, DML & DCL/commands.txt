Q10
CREATE ROLE readonly_user WITH LOGIN PASSWORD 'Student@123';
GRANT USAGE ON SCHEMA academics TO readonly_user;
GRANT SELECT ON academics.students TO readonly_user;

Q11
REVOKE SELECT ON academics.students FROM readonly_user;

If readonly_user tries to run select query, it will give error: permission denied for table students because select privilege was revoked.
